# Portfolio Agritech - RAKOTOARIVAO Tokiniaina Eddy

Ce projet est un portfolio personnel orienté "Agritech", conçu pour présenter mon profil, mes services et mes projets autour de l’agriculture, de la data et des technologies numériques.

## Aperçu

Le site contient :
- Une section "Hero"avec présentation rapide et photo de profil
- Une section "About" (à propos)
- Une section "Services"
- Une section "Projects"
- Une section "Contact"

Le design est moderne, responsive, avec un thème vert dégradé et des animations légères.

## Technologies utilisées

- `HTML5`
- `CSS3`
- `JavaScript` (vanilla)

## Structure du projet

```text
Portfolio Website/
├── assets/
│   └── profile.jpg
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Lancer le projet

1. Ouvrir le dossier du projet.
2. Ouvrir `index.html` directement dans un navigateur.

Aucune installation de dépendances n’est nécessaire.

## Personnalisation rapide

- Modifier les textes : `index.html`
- Modifier les couleurs et styles : `styles.css`
- Modifier les interactions/animations : `script.js`
- Remplacer la photo : `assets/profile.jpg`
